# ComicRich — CDisplayEx Discord Rich Presence

Неофициальный компаньон для [CDisplayEx](https://www.cdisplayex.com/): показывает в Discord,
какой комикс вы читаете — обложку, название, выпуск, страницу, а для сборников — какой выпуск
внутри сборника открыт сейчас.

```
Смотрит  Runaways #1: Pride and Joy, Chapter 1 of 6
         Runaways, том 1 (2003) · Стр. 17 из 25
```

ComicRich запускается сам при двойном клике по комиксу и завершается через 15 секунд после
закрытия CDisplayEx. Когда вы не читаете, он не работает вовсе.

## Возможности

- Определение открытого файла и текущей страницы без плагинов и без вмешательства в CDisplayEx.
- CBZ, CBR (RAR4/RAR5), архивы внутри архивов, PDF.
- Метаданные из `ComicInfo.xml`, имени файла и папки (`Runaways Vol 1\Runaways 01.cbr`).
- Официальные названия и обложки из [Metron](https://metron.cloud) и [Comic Vine](https://comicvine.gamespot.com/api).
- Тип издания: выпуск онгоинга (с названием тома), лимитка («выпуск 3 из 6»), ван-шот, ежегодник, сборник.
- Сборники: какой выпуск читается сейчас — по папкам, закладкам ComicInfo или по обложкам выпусков,
  найденным среди страниц. Неуверенная оценка помечается «≈», неопознанные участки остаются без номера.
- Несколько окон CDisplayEx одновременно: статус следует за окном, с которым вы работаете.

## Установка

1. Создайте приложение в [Discord Developer Portal](https://discord.com/developers/applications)
   (или используйте встроенный Application ID) и загрузите иконку приложения — она показывается,
   когда обложки нет.
2. Скопируйте `comicrich.example.toml` рядом с `comicrich.exe` под именем `comicrich.toml`
   и при желании впишите доступы к Metron и/или Comic Vine.
3. Выполните:

   ```
   comicrich.exe --install
   ```

   Программа и настройки копируются в `%LOCALAPPDATA%\ComicRich\`, а двойной клик по `.cbz`/`.cbr`
   начинает запускать ComicRich, который сразу открывает CDisplayEx. Права администратора не нужны:
   меняется только команда открытия для текущего пользователя
   (`HKCU\Software\Classes\<тип файла CDisplayEx>\shell\open\command`); значки и миниатюры остаются
   от CDisplayEx.

После переустановки или обновления CDisplayEx выполните `--install` ещё раз.

## Отключение

```
%LOCALAPPDATA%\ComicRich\comicrich.exe --uninstall
```

Комиксы снова открываются напрямую в CDisplayEx. Папку `%LOCALAPPDATA%\ComicRich\` после этого
можно удалить.

## Настройки (`comicrich.toml`)

| Поле | Значение |
|---|---|
| `app_id` | Discord Application ID |
| `language` | `"ru"` или `"en"` — язык статуса |
| `online` | `true`/`false` — искать комиксы в онлайн-базах |
| `[metron] username`, `password` | бесплатный аккаунт metron.cloud (основная база) |
| `[comicvine] api_key` | бесплатный ключ Comic Vine (запасная база) |

Файл хранит пароль открытым текстом и исключён из git.

## Нагрузка и данные

- Exe ~4 МБ; в простое процессор не используется — изменения окон приходят событиями Windows.
- Обычный выпуск: 2–4 запроса к базе один раз. Сборник: разбор обложек один раз, 40–85 с
  (в основном ожидание лимитов Metron), 6–19 с процессорного времени на самом низком
  фоновом приоритете.
- Кэш: `%LOCALAPPDATA%\ComicRich\cache.json`, около 2 КБ на комикс, только текст. Сам очищается от
  удалённых, изменённых и не открывавшихся больше года комиксов.
- В сеть уходят только запросы к Metron/Comic Vine, загрузка обложек для сравнения и чтение
  публичной информации о приложении Discord. Локальные файлы никуда не загружаются.

## Диагностика

| Команда | Что делает |
|---|---|
| `comicrich.exe --debug` | работа с журналом в консоли (без автозавершения) |
| `set COMICRICH_LOG=путь\к\файлу.log` | журнал в файл, в том числе при запуске двойным кликом |
| `comicrich.exe --list <файлы>` | что программа понимает о файлах без сети |
| `comicrich.exe --lookup <файлы>` | полный разбор с онлайн-поиском и поиском выпусков в сборнике |

## Ограничения

- Если CDisplayEx открыт не двойным кликом (меню «Пуск», ярлык), ComicRich не запускается.
- Discord не позволяет статус «Читает», поэтому используется ближайший тип — «Смотрит».
- Проверено на CDisplayEx 1.10.33.

## Сборка

```
cargo build --release
```

Нужны Rust (stable, MSVC) и Visual Studio Build Tools с компонентом C++ (для распаковки RAR).
