# ComicRich - CDisplayEx Discord Rich Presence

[English](README.md) · **Русский**

Неофициальный компаньон для читалки комиксов [CDisplayEx](https://www.cdisplayex.com/): показывает
в Discord, что вы читаете, — обложку, название, выпуск и страницу, а для сборников — какой выпуск
внутри сборника открыт сейчас.

```
Смотрит  Runaways #7: Rock Zombies: Part One
         Runaways, том 3 (2009) · Стр. 1 из 24
```

ComicRich запускается сам при двойном клике по комиксу и завершается через 15 секунд после того,
как закрыто последнее окно CDisplayEx. Когда вы не читаете, он не работает вовсе.

## Возможности

- Определение открытого файла и текущей страницы без плагинов и без вмешательства в CDisplayEx.
- CBZ/ZIP, CBR/RAR (RAR4 и RAR5), архивы внутри архивов, PDF. Другие форматы (например, CB7)
  показываются по имени файла.
- Метаданные из `ComicInfo.xml`, имени файла и папки (`Runaways Vol 1\Runaways 01.cbr`).
- Официальные названия и обложки из [Metron](https://metron.cloud) и
  [Comic Vine](https://comicvine.gamespot.com/api): ищутся один раз и запоминаются.
- Тип издания: выпуск онгоинга (с номером тома), лимитка («выпуск 3 из 6»), ван-шот, ежегодник,
  графический роман, сборник.
- Сборники: какой выпуск читается сейчас — по папкам, закладкам ComicInfo или по обложкам выпусков,
  найденным среди страниц. Приблизительная оценка помечается «≈», неопознанные участки остаются
  без номера.
- Несколько окон CDisplayEx одновременно: статус следует за окном, с которым вы работаете.
- Комиксы, открытые через меню самого CDisplayEx, тоже отслеживаются.

## Требования

- Windows 10 или 11.
- [CDisplayEx](https://www.cdisplayex.com/) (проверено на 1.10.33), назначенный программой для
  комиксов.
- Приложение Discord для компьютера.

## Установка

1. Скачайте `comicrich.exe` из [последнего выпуска](../../releases/latest).
2. Запустите его двойным кликом и ответьте **Yes** на вопрос «Install it?».
3. По желанию: когда программа предложит, откройте настройки и впишите токен Metron или ключ
   Comic Vine (см. ниже) — для официальных названий и обложек. Без них названия берутся из файлов.

Готово: откройте комикс двойным кликом, и его обложка и название появятся в статусе Discord.

При первом запуске Windows может предупредить «Система Windows защитила ваш компьютер» — так она
реагирует на любую новую программу без цифровой подписи. Нажмите **Подробнее → Выполнить в любом
случае**.

Программа вместе с настройками копируется в `%LOCALAPPDATA%\ComicRich\`, а двойной клик по
`.cbz`, `.cbr` или `.cb7` начинает запускать ComicRich, который сразу открывает CDisplayEx. Права
администратора не нужны: меняется только команда открытия для типа файлов CDisplayEx у текущего
пользователя (`HKCU\Software\Classes\<тип файла CDisplayEx>\shell\open\command`); значки и
миниатюры остаются от CDisplayEx.

**Обновление:** запустите новый `comicrich.exe` двойным кликом и ответьте **Yes** на вопрос
«Replace it with this version?». Настройки сохраняются. Так же поступите, если после переустановки
или обновления CDisplayEx двойной клик по комиксу перестал запускать ComicRich.

То же самое можно сделать из терминала: `comicrich.exe --install`.

### Онлайн-базы (по желанию)

Обе бесплатны. Сначала используется Metron, Comic Vine — запасная.

- **Metron:** зарегистрируйтесь на [metron.cloud](https://metron.cloud), затем создайте токен в
  разделе **API Tokens** на странице своего аккаунта и впишите его в `token`.
- **Comic Vine:** зарегистрируйтесь на [comicvine.gamespot.com](https://comicvine.gamespot.com/)
  и скопируйте ключ со [страницы API](https://comicvine.gamespot.com/api/) в `api_key`.

## Настройки

Чтобы открыть настройки, запустите `comicrich.exe` двойным кликом (скачанный или
`%LOCALAPPDATA%\ComicRich\comicrich.exe`) либо откройте в Блокноте
`%LOCALAPPDATA%\ComicRich\comicrich.toml`. Все поля необязательные; изменения применяются при
следующем открытии комикса.

| Поле | Значение |
|---|---|
| `app_id` | ID приложения Discord; по умолчанию — приложение ComicRich |
| `language` | `"ru"` или `"en"` — язык текста статуса |
| `online` | `true`/`false` — искать комиксы в онлайн-базах |
| `[metron] token` | токен API Metron |
| `[metron] username`, `password` | вместо токена; Metron считает этот способ устаревшим |
| `[comicvine] api_key` | ключ API Comic Vine |

Файл хранит доступы открытым текстом — не передавайте его другим.

Чтобы использовать своё приложение Discord (Discord показывает его название и значок), создайте его
в [Discord Developer Portal](https://discord.com/developers/applications), загрузите значок — он
показывается, когда обложки нет, — и впишите `app_id`.

## Отключение

Удаляется ComicRich как любая программа: **Параметры → Приложения → Установленные приложения →
ComicRich → Удалить**. Комиксы снова открываются напрямую в CDisplayEx, а сохранить ли настройки и
кэш — вы выберете сами.

Из терминала: `%LOCALAPPDATA%\ComicRich\comicrich.exe --uninstall` (папка
`%LOCALAPPDATA%\ComicRich\` остаётся, её можно удалить вручную).

## Как это работает

У CDisplayEx нет интерфейса для плагинов, поэтому ComicRich наблюдает за ним снаружи:

- заголовок главного окна — в нём имя показываемой картинки (`Inner.cbr\Page 003.jpg`);
- командная строка каждого процесса CDisplayEx — в ней файл, по которому дважды щёлкнули;
- файлы, которые CDisplayEx (или его помощник для PDF) держит открытыми, пока загружает другой
  комикс;
- состояние CDisplayEx в реестре — его история и сохранённые страницы.

Имя картинки сопоставляется со списком страниц архива, так находится номер страницы. Статус
передаётся приложению Discord через его локальное подключение (Discord RPC).

## Приватность и ресурсы

- В сеть уходят только запросы к Metron и Comic Vine (название серии, год и номер выпуска),
  загрузка их обложек для распознавания выпусков в сборниках и публичная информация о приложении
  Discord. Ваши файлы никуда не загружаются.
- Кэш `%LOCALAPPDATA%\ComicRich\cache.json` — около 2 КБ текста на комикс. Сам очищается от
  удалённых, изменённых и не открывавшихся больше года комиксов.
- Около 4 МБ на диске; в простое процессор не используется — изменения окон приходят событиями
  Windows.
- Комикс ищется один раз: 2–4 запроса, для следующего выпуска той же серии — 2. Распознавание
  выпусков сборника — один раз, до двух минут, на самом низком фоновом приоритете.

## Ограничения

- ComicRich запускается только двойным кликом. Если CDisplayEx открыт иначе (меню «Пуск», ярлык),
  а ComicRich ещё не запущен, статуса не будет.
- В Discord нет статуса «Читает», поэтому используется «Смотрит».
- Discord принимает новые подключения примерно раз в 30 секунд: если открывать и закрывать комиксы
  очень часто, статус может появиться с такой задержкой.
- Metron разрешает 20 запросов в минуту и 5000 в сутки. ComicRich делает не больше 18 в минуту и
  следит за остатком, который сообщает Metron; если лимит исчерпан надолго, используется Comic Vine.
- Если Metron отклонил токен или пароль, ComicRich больше не обращается к нему, пока доступы не
  изменятся: Metron блокирует адреса, с которых повторяются неверные входы.

## Решение проблем

| Команда | Что делает |
|---|---|
| `set COMICRICH_LOG=C:\путь\к\файлу.log` | журнал в файл, в том числе при запуске двойным кликом (задайте в переменных среды Windows) |
| `comicrich.exe --debug` | работа с журналом в консоли (без автозавершения) |
| `comicrich.exe --list <файлы>` | что ComicRich понимает о файлах, без сети |
| `comicrich.exe --lookup <файлы>` | полный разбор с онлайн-базами и поиском выпусков в сборнике |

## Сборка

```
cargo build --release
```

Нужны Rust (stable, MSVC) и Visual Studio Build Tools с компонентом C++ (для библиотеки RAR).

## Тесты

```
cargo test
```

Сквозные тесты открывают настоящие окна CDisplayEx (двойным кликом и через диалог «Открыть»),
листают страницы и проверяют статус в Discord, поэтому запускаются только явно. Нужны запущенный
Discord и `comicrich.toml` рядом с тестовой сборкой (`target\debug`). Сохранённые страницы
CDisplayEx после тестов восстанавливаются.

```
set COMICRICH_E2E_COMIC=D:\Comics\Серия\Выпуск 07.cbz      (обязательно; берётся и следующий файл в папке)
set COMICRICH_E2E_COLLECTION=D:\Comics\Сборник.cbz         (выпуск должен начинаться в первых 13 страницах)
set COMICRICH_E2E_NESTED=D:\Comics\Архив в архиве.cbr.cbr
set COMICRICH_E2E_PDF=D:\Comics\Большой скан.pdf
cargo test --test e2e -- --ignored --nocapture --test-threads=1
```

Проверяются: обложка при первом открытии и из кэша, открытие через меню (в том числе PDF), два окна
одновременно и автозавершение, текущий выпуск внутри сборника, архивы в архивах и PDF.
